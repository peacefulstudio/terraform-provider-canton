# Canton Provider

The Canton provider manages resources on a [Canton](https://www.canton.io/) participant node via the participant admin gRPC services. It supports:

- **Parties** — allocate and look up parties
- **Users** — create and delete users
- **User rights** — grant, revoke, and update rights (act-as, read-as, admin roles)

## Authentication

The provider connects to a Canton participant's gRPC endpoint. If the participant requires OAuth2 authentication, configure the `oauth2` block or set the corresponding environment variables.

| HCL Attribute | Environment Variable |
|---------------|---------------------|
| `participant_url` | `CANTON_PARTICIPANT_URL` |
| `oauth2.token_url` | `CANTON_OAUTH2_TOKEN_URL` |
| `oauth2.client_id` | `CANTON_OAUTH2_CLIENT_ID` |
| `oauth2.client_secret` | `CANTON_OAUTH2_CLIENT_SECRET` |
| `oauth2.audience` | `CANTON_OAUTH2_AUDIENCE` |
| `oauth2.scope` | `CANTON_OAUTH2_SCOPE` |

## Example Usage

```terraform
terraform {
  required_providers {
    canton = {
      source  = "peacefulstudio/canton"
      version = "~> 0.1"
    }
  }
}

provider "canton" {
  participant_url = "https://participant.example.com"

  oauth2 {
    token_url     = "https://auth.example.com/oauth/token"
    client_id     = var.canton_client_id
    client_secret = var.canton_client_secret
    audience      = "https://canton.example.com"
  }
}
```
