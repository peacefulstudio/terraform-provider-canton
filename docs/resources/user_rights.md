# canton_user_rights (Resource)

Manages rights granted to a user on a Canton participant node. Rights can be updated in-place — the provider computes the diff and grants/revokes only the changed rights.

## Example Usage

```terraform
resource "canton_party" "treasury" {
  party_id_hint = "treasury"
}

resource "canton_party" "validator" {
  party_id_hint = "validator"
}

resource "canton_user" "treasury_service" {
  user_id       = "treasury-service"
  primary_party = canton_party.treasury.party_id
}

resource "canton_user_rights" "treasury_rights" {
  user_id = canton_user.treasury_service.user_id

  act_as  = [canton_party.treasury.party_id]
  read_as = [canton_party.validator.party_id]

  participant_admin       = false
  identity_provider_admin = false
}
```

## Schema

### Required

- `user_id` (String) The target user ID.

### Optional

- `act_as` (Set of String) Set of party IDs the user can act as.
- `identity_provider_admin` (Boolean) Whether the user has identity provider admin rights.
- `participant_admin` (Boolean) Whether the user has participant admin rights.
- `read_as` (Set of String) Set of party IDs the user can read as.

