# terraform-provider-canton v0.1.1

Patch release — first version installable via the Terraform Registry.

## What's new since v0.1.0

### Terraform Registry compatibility

The release artifact set now includes a SHA256 checksum entry for `terraform-provider-canton_<version>_manifest.json`. The Terraform Registry validates that every file referenced by a release is checksummed before accepting the version, so v0.1.0 — which checksummed only the binary archives — could not be published. v0.1.1 closes that gap and is the first Registry-installable release.

No provider behaviour changes since v0.1.0; this is a release-pipeline fix only.

## Getting started

```hcl
terraform {
  required_providers {
    canton = {
      source  = "peacefulstudio/canton"
      version = "~> 0.1.1"
    }
  }
}

provider "canton" {
  participant_url = "https://participant.example.com"

  oauth2 {
    token_url     = "https://auth.example.com/oauth/token"
    client_id     = var.canton_client_id
    client_secret = var.canton_client_secret
    audience      = "https://canton.example.com"
  }
}
```
